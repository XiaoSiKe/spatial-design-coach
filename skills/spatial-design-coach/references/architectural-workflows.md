# 建筑与空间设计专项工作流

从学生要做的动作和当前源文件选择一条主工作流。已有产物可直接进入验收。有前后依赖时，按源图、模型、表达、交付的顺序推进。沿用项目的任务书、版本、锁定决定和已知边界。技术成果需要实际工具产物与可复核依据。只有投影、生成图或参考图时，将看不见的部分和未经验证的结论列为待查。

这些是根据建筑学长 AI 的公开工具目录独立编写的辅导流程。在当前环境调用已可用的工具。需要移交时，用[能力路由](capability-routing.md)的目录、结果记录、三类后果与回传审计；缺少工具时给具体手工步骤和验收。只改变本轮指定的变量，保留同一源文件版本，涉及已锁定的决定时请学生确认后再改。

## 方案与技术图

| 工作流 | 输入与动作 | 最小成果及通过条件 |
| --- | --- | --- |
| W01 · 设计助手、画布与资料检索 | 用任务书、场地和当前图纸列出待决定问题。把参考图、案例、方案分支和验证图挂回同一条决策链；规范或性能问答交给 `research-current`。 | 一份有来源和版本的方案分支记录。每张关键图能对应一个决定和待核项，参考与证据可追溯。 |
| W02 · 概念意象、草图与参考图 | 从文字、草图或有来源的图像中提取可描述的空间关系，例如门廊深浅、路径选择、明暗过渡。保持场地约束，比较两种空间机制；视觉参考可交给 `visual`。 | 两张同边界的草图和各自一条代价。学生能指出每张图检验的空间关系，拼图、反推提示词和风格参考附来源。 |
| W03 · 体块、规划总图和强排 | 输入红线、现状、目标指标、北向、主要出入口及须保留关系。用两个体量组织分别测试容量、住区开敞空间及到达；需要计算或模型时转 `cad-modeling`、`geospatial`。 | 同基准总图、面积/容量口径和一条共同剖切线。边界、体量、路径可追踪，未知指标和合规结论仍列待核。 |
| W04 · 地形获取、GIS 与 CAD 转地形 | 用带来源与日期的地形、坐标系、垂直基准和单位叠加道路水系；等高线高程缺失时标注缺口，沿关键沟谷、路堤和折线控制插值。调用 `geospatial`，需要可编辑几何时转 `cad-modeling`。 | 地形文件、标高点对照表及交叉剖面。导入回读后对齐控制点、边界、坡向和单位，未知高程不得用生成图补齐。 |
| W05 · 旧房、场地、市政和门头改造 | 输入现状照片、实测底图、可拆与保留边界以及实际使用。先描出现状，画介入掩膜，比较微改与重点重组。效果转 `visual`，现场与构造核实各自留证。 | 同视点前后图加一张现状与改造对照平面。能定位保留构件、出入口、公共路径和新增干预，照片无法确认的构件注明待查。 |
| W06 · 日照、气候和绿色建筑性能 | 明确要比较的指标，列地点、北向、几何版本、遮挡、气象或日期时段、采样点及标准出处。用 `research-current` 查适用依据，并调用实际具备模拟能力的工具。 | 记录参数、结果与敏感性检查，能从源模型复跑。概念日影、灯光画面和实测／规范结论分别标明，缺数据时保留未测试。 |
| W07 · 读图制图、草图转 CAD、平立剖与机电示意 | 输入可核的锚点、比例尺、图例和源图版本。可先转线稿，再在 `cad-modeling` 中校准、分层并建立编号。剖面从已知剖切线重建，未知背面或机电路径做占位和待核。 | 可编辑图纸与实际回读或打印样本，检查主要净尺寸、轴线、标高、图层和剖切对应。尺寸来源与图像推断区分，机电与消防要求由专业资料和复核支撑。 |
| W08 · 白模、图转模型、CAD 户型转 3D 与参数化建模 | 输入源平面或多视图、单位、原点、层高和至少一个可核尺寸。先搭体量、楼层和主要开口，再确定编辑深度。单图缺失面和遮挡处先占位。调用 `cad-modeling`。 | 模型、版本、格式和回读截图。同源平剖对上墙体、层高、洞口、方向和原点，生成的白模图仍按视觉参考使用。 |
| W09 · 立面设计和界面迁移 | 用平面、白模、朝向、开口与材料逻辑，提取参考中的遮阳深度、支撑节奏或虚实关系，在同轴网出两版。视觉试探用 `visual`，可编辑立面用 `cad-modeling`。 | 立面与局部剖面，对齐楼层、开口、构件与排水关系。效果参考保留来源，重复样式前核对各朝向、结构与维护。 |
| W10 · 室内布局、整屋定制、家具、软装和舞台 | 使用有比例户型、实测门窗、用户活动及家具尺寸。先查出入、净空、开门与布置，再测试照明、材质或陈设。舞台另记录观众、表演、后台和临时构件的分流。 | 同尺度两版家具平面加一张关键节点图。能沿真实路线核对碰撞、可达与活动包络，效果图中新添或推断的构件待校。 |
| W11 · 渲染、灯光、夜景和氛围 | 从源模型锁定相机、主要几何与约束，每轮调整材质、灯位、时间或天气之一。外观用 `visual`，照度或能耗要求接 W06。 | 固定视点对照、参数与图像。几何锚点对应源图，能解释光源位置与目标氛围，视觉模拟单独标明。 |
| W12 · 彩平、分析图、节点图与爆炸图 | 从已核总图或同版模型提取图层，给每张图一个问题。按源资料画路径、功能、竖向或植物，明确图例、尺度与版本。 | 图上每条关键线或色块可回到源图、数据或假设；抽查边界和锚点。分析图新增的箭头、范围或标高逐一校验。 |
| W13 · 平面转透视、鸟瞰互转、多视角与全景 | 固定北向、相机、关键转角、开口和基准，用源图或模型约束交付。全景输出检查投影格式、地平线与接缝。对图转图中推断的几何作显式标记。 | 两张同版本视图及标注过的源图；抽查至少两个空间锚点和一个人行关系。生成视图用于沟通，技术校图从 W07 或 W08 取证。 |
| W14 · 局部改图、材质、融合、拼贴和出图通道 | 指定参考、编辑区域、相机与保留几何。在副本上做局部替换、透视融合、分通道导出、配色或环境变化。保留原图便于叠对。 | 原图、区域掩膜、改图及比对；核对边界外变化、接缝、阴影、图例和比例。使用参考素材时记录授权，水印／署名按权利状态处理。 |
| W15 · 家具产品表达和预算概算 | 从实测、可编辑图或已确认产品表取得尺寸、数量、材料与工序。用家具三视图／棚拍表达既定物件；概算按数量、单位、来源日期、地区、范围和未计项建表。 | 可复算的工程量/估算表或有产品出处的图组。没有测量时给构成与缺项，报价结论要用当地有效数据和实际工程范围核对。 |
| W16 · 图像清理、修复和导出 | 核对输出用途、像素或印刷尺寸与原始图。用 `visual` 或 `presentation-document` 做抠图、清理、文字纠错、尺寸转换、增强或压缩。 | 导出件和原件可对照。实际输出尺寸上文字、细线、标注、颜色和授权署名可读，修复重绘的纹理不能作为事实细节引用。 |
| W17 · 分镜、图生视频与漫游 | 在经确认的路径上给每个镜头一个任务，标楼层、观察位置、方向和转接点。用 `visual` 生成或剪辑，设计动线冲突回到平剖修正。 | 分镜索引和视频样本；镜头按真实行走关系串联，检查物体漂移、空间跳变、字幕和源模型对应。 |
| W18 · 展板、PPT、汇报网页与文件整理 | 结合任务书的尺寸、张数、时长和格式，从同版本成果取图并分配论证任务。用 `presentation-document` 输出可编辑源与成品。网页用相应网页制作能力处理。 | 可导出文件与最终尺寸检查记录。叙事可按问题、依据、策略、图纸验证排列，每张关键图的版本和来源可查。 |
| W19 · 花境、绿化和种植设计 | 输入真实光水土条件、目标季相、维护能力和临近铺装。用种植断面比较垂直层次与群落的时间变化，场景图依附该断面。 | 两时段种植剖面及初选表，标注根域、遮阴、通行及养护接口。树种与性能以当地适生信息和项目数据复核。 |

## 常见串联

- **彩平转鸟瞰。** 从 W12 确认源图，接 W13。鸟瞰里建筑入口、公共路径和两处保留对象与总图逐一对应后，才进入 W18。
- **手绘重画可编辑 CAD。** 用 W07 区分实测尺寸、可校准线段和不可见部分。回读图纸核过单位、两处尺寸和图层后，再进 W08 生成共享模型。
- **滨水更新方案。** 用 W04 核地形、用 W05 比较保留边界，选 P17/P19 的[书籍方法](professional-book-methods.md)检查水路和日常通行。W11 的画面只展示已经对齐的方案版本。
